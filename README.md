# 双动量回测（GEM + 现有 CTA）

这是一个**独立项目**，用来回测 Gary Antonacci 的 GEM 双动量，并把它和现有 CTA 切换账按核心/卫星接在一起。它只读取你已经有的 CTA / TradingView 代码和日线缓存，**不会改写那些项目里的任何文件**。新标的的行情只会写进本目录的 `cache/`。

## 规则（已冻结，不做参数搜索）

月底用过去 12 个月总回报做一次决定，下个月持有：

1. 绝对动量：若 SPY 的 12 个月收益高于 BIL，则为风险开；否则整仓持有 AGG。
2. 相对动量：风险开时，持有 SPY 与国际篮子中 12 个月收益更高的那个。国际篮子是每日再平衡的 50% EWJ（日本）+ 50% ASHR（中国 A 股），用来替代原来的 EFA。

信号在月底收盘写入，仓位赚下一根 K 线的收益，和现有 CTA 的滞后规则一致。成本列 0 bps 与 5 bps。

接法是 **核心 70 / 卫星 30**：70% GEM + 30% 现有 CTA 切换账（按你当前名单，等权、无杠杆）。对照还包括单独的 GEM、单独的 CTA 切换账，以及买入持有 SPY。不再计算核心满仓再叠加 CTA 的杠杆接法。

净值对比图下方另有一条一年（252 个交易日）滚动夏普，计算方式和汇总表里的夏普一致：日收益均值除以标准差，再乘以 \(\sqrt{252}\)，无风险利率按 0。


另外可以把整套核心/卫星策略再当作“风险仓”，按 **策略 70 / IEF CTA 30** 搭配：70% 给上面的 70/30 策略，30% 给 IEF（iShares 7-10 年美债 ETF）的 CTA 切换仓。IEF 这条腿顶底背离都做，没有背离信号时走动量，仓位在 -100% 到 100% 之间，再乘上 30%。权重每日再平衡，和现有核心/卫星接法一致。原来的买入持有 IEF，以及策略 70 / 买入持有 IEF 30，留在同一张图里作对照。这条从 2017 年起对买入持有 SPY 比较，图在 `output/<日期>/equity_compare_alloc_2017.png`。

## 运行

本项目可以借用现有 CTA 的虚拟环境，不必先改那个项目：

```bash

"/Users/yanyunfeng/文稿/cta/.venv/bin/python" run_dual_mom.py
```

如果 CTA 项目不在默认路径，先设置 `CTA_ROOT`。结果在 `output/<日期>/`。
